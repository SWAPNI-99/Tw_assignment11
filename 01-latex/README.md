# Module 1: LaTeX — Scientific & Technical Typesetting

LaTeX (pronounced *LAH-tekh* or *LAY-tekh*) is a high-quality typesetting system designed for technical, academic, and scientific documentation. Unlike standard "What You See Is What You Get" (WYSIWYG) word processors, LaTeX operates on the **"What You See Is What You Mean" (WYSIWYM)** philosophy, separating document content from visual styling.

## 1. Introduction to LaTeX

### Why LaTeX?
- **Superior Math Engine:** World-class rendering of complex mathematical, physical, and chemical notations.
- **Consistent Formatting:** Global styling managed via macros and classes without manual micro-adjustments.
- **Automated Mechanics:** Automatic generation of Table of Contents, List of Figures, citations, bibliographies, and cross-references.
- **Plain Text Portability:** Files are simple `.tex` text files compatible with version control systems like Git.
- **Industry Standard:** Required by IEEE, ACM, Springer, Elsevier, and major university thesis departments.

## 2. Compilation Workflow & Architecture

A LaTeX document starts as plain text in a `.tex` file and compiles into a finished `.pdf` document through a compilation engine.

```text
+--------------+       +-------------------+       +-----------------+
|  source.tex  | ----> |  pdflatex/xelatex | ----> |   document.pdf  |
+--------------+       +-------------------+       +-----------------+
       |                        ^                           |
       |                        | (Multiple passes)         |
       v                        |                           v
+--------------+       +-------------------+       +-----------------+
|  source.bib  | ----> |      bibtex       |       |  .aux/.log/.out |
+--------------+       +-------------------+       +-----------------+
```

### Key Auxiliary Files:
- `.aux`: Auxiliary file containing cross-reference and citation keys.
- `.log`: Detailed compiler transcript log (inspect this when errors occur).
- `.bbl`: Formatted bibliography output generated by `bibtex`.
- `.toc` / `.lot` / `.lof`: Table of Contents, Lists of Tables/Figures.

### Standard Compilation Commands (Terminal):
```bash
# Full compilation with citations and cross-references:
pdflatex document.tex
bibtex document.aux
pdflatex document.tex
pdflatex document.tex
```

## 3. Document Anatomy & Preamble

Every LaTeX file is split into two primary parts:
1. **The Preamble:** Configures document type, global margins, packages, metadata, and custom commands.
2. **The Document Body:** Enclosed within `\begin{document}` and `\end{document}`.

```latex
% 1. PREAMBLE
\documentclass[11pt,a4paper]{article}

% Load packages
\usepackage[utf8]{inputenc}
\usepackage{amsmath,amssymb}
\usepackage{graphicx}
\usepackage{hyperref}

% Metadata
\title{Introduction to LaTeX Typesetting}
\author{Your Name}
\date{\today}

% 2. DOCUMENT BODY
\begin{document}

\maketitle

\begin{abstract}
This document demonstrates the core principles of LaTeX typesetting.
\end{abstract}

Hello, world! This is my first LaTeX document.

\end{document}
```

### Standard Document Classes:
- `article`: Short papers, lab reports, homework assignments, journal articles.
- `report`: Longer technical documents, undergraduate/master's theses (supports chapters).
- `book`: Full-length books (supports frontmatter, mainmatter, backmatter, chapters).
- `beamer`: Presentation slides.

## 4. Essential LaTeX Packages

| Package | Purpose | Typical Usage |
|---------|---------|---------------|
| `amsmath`, `amssymb` | Advanced mathematics, symbols, align environments | `\usepackage{amsmath,amssymb}` |
| `geometry` | Customizing page margins, paper dimensions | `\usepackage[margin=1in]{geometry}` |
| `graphicx` | Inserting external raster/vector images | `\usepackage{graphicx}` |
| `hyperref` | Clickable hyperlinks, internal bookmarks | `\usepackage[colorlinks=true,linkcolor=blue]{hyperref}` |
| `booktabs` | Clean, professional, publication-grade tables | `\usepackage{booktabs}` |
| `listings` / `minted` | Code block highlighting | `\usepackage{listings}` |
| `cite` / `biblatex` | Academic citations and references management | `\usepackage{biblatex}` |

## 5. Text Formatting & Document Hierarchy

### Document Hierarchy:
```latex
\section{First Major Topic}
\subsection{Sub-topic Details}
\subsubsection{Fine-grained Point}
\paragraph{Paragraph Header}
```

### Text Styling:
- **Bold:** `\textbf{bold text}`
- *Italics:* `\textit{italic text}` or `\emph{emphasized text}`
- <u>Underline:</u> `\underline{underlined text}`
- `Monospace / Code:` `\texttt{inline_code()}`
- *Small Caps:* `\textsc{Small Caps}`
- Font Sizes: `\tiny`, `\small`, `\normalsize`, `\large`, `\Large`, `\huge`, `\Huge`

### Lists:
```latex
% Unordered List (Bullet Points)
\begin{itemize}
    \item First bullet point
    \item Second bullet point with sub-item:
    \begin{itemize}
        \item Sub-point A
    \end{itemize}
\end{itemize}

% Ordered List (Numbered)
\begin{enumerate}
    \item Step 1: Initialize git repository
    \item Step 2: Stage and commit files
\end{enumerate}
```

## 6. Mathematical Typesetting

LaTeX is renowned for its mathematical engine.

### Inline vs. Display Math:
- **Inline Math:** Wrapped in single dollar signs `$E = mc^2$`. Used inside sentences.
- **Display Math:** Centered on its own line using `\[ ... \]` or the `equation` environment:

```latex
\[
\int_{a}^{b} f(x) \, dx = F(b) - F(a)
\]
```

### Common Mathematical Constructs:

#### Fractions and Roots:
```latex
\frac{numerator}{denominator}    % \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
\sqrt[n]{x}                      % \sqrt{x^2 + y^2}
```

#### Summations, Products, and Integrals:
```latex
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
\prod_{k=1}^{\infty} \left(1 - \frac{1}{p_k^2}\right)
\lim_{x \to 0} \frac{\sin(x)}{x} = 1
```

#### Multi-line Aligned Equations (`amsmath`):
```latex
\begin{align}
    f(x) &= (x + 3)^2 \\
         &= x^2 + 6x + 9
\end{align}
```

#### Matrices:
```latex
\begin{bmatrix}
    a_{11} & a_{12} \\
    a_{21} & a_{22}
\end{bmatrix}
```

#### Greek Letters:
- Lowercase: `\alpha`, `\beta`, `\gamma`, `\theta`, `\lambda`, `\pi`, `\sigma`, `\omega`
- Uppercase: `\Gamma`, `\Delta`, `\Theta`, `\Lambda`, `\Sigma`, `\Omega`

## 7. Tables and Figures

### Clean Tables with `booktabs`:
Avoid vertical lines (`|`) in scientific papers for a cleaner, professional presentation.

```latex
\begin{table}[htbp]
    \centering
    \caption{Experimental Results Summary}
    \label{tab:results}
    \begin{tabular}{llr}
        \toprule
        Method & Accuracy (\%) & Latency (ms) \\
        \midrule
        Baseline Linear & 84.2 & 12.4 \\
        Support Vector Machine & 91.5 & 45.1 \\
        Deep Neural Network & 96.8 & 88.0 \\
        \bottomrule
    \end{tabular}
\end{table}
```

### Floating Figures:
```latex
\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.7\textwidth]{figures/architecture.png}
    \caption{System Pipeline Architecture}
    \label{fig:arch}
\end{figure}
```
*Note on float placement specifiers:* `h` (here), `t` (top), `b` (bottom), `p` (page of floats).

## 8. Cross-Referencing & Citations (BibTeX)

### Internal References:
Use `\label{key}` to mark any section, table, or figure, and reference it with `\ref{key}`:
```latex
As shown in Table~\ref{tab:results} and illustrated in Figure~\ref{fig:arch}...
```

### BibTeX Bibliography Management:
Store citations in a `.bib` file (e.g., `references.bib`):

```bibtex
@book{knuth1984texbook,
  author    = {Donald E. Knuth},
  title     = {The {\TeX}book},
  year      = {1984},
  publisher = {Addison-Wesley}
}

@article{lamport1986latex,
  author    = {Leslie Lamport},
  title     = {{\LaTeX}: A Document Preparation System},
  year      = {1986},
  journal   = {Addison-Wesley}
}
```

Cite them in your `.tex` file using:
```latex
This concept was originally formalized by Knuth~\cite{knuth1984texbook}.

% At the end of the document:
\bibliographystyle{plain}
\bibliography{references}
```

## 9. Complete Working Code Example

Save this snippet as `document.tex` to test:

```latex
\documentclass[12pt,a4paper]{article}
\usepackage[margin=1in]{geometry}
\usepackage{amsmath,amssymb}
\usepackage{booktabs}
\usepackage{hyperref}

\title{\textbf{Sample Laboratory Report in \LaTeX}}
\author{Jane Doe \and John Doe}
\date{\today}

\begin{document}
\maketitle

\section{Introduction}
LaTeX provides precise typography and deterministic document compilation. In this report, we evaluate the function described in Equation~\eqref{eq:gaussian}.

\section{Mathematical Analysis}
The one-dimensional Gaussian distribution function is defined as:
\begin{equation}
    f(x) = \frac{1}{\sigma \sqrt{2\pi}} \exp\left( -\frac{(x - \mu)^2}{2\sigma^2} \right)
    \label{eq:gaussian}
\end{equation}
where:
\begin{itemize}
    \item $\mu$ denotes the expected value (mean).
    \item $\sigma^2$ represents the variance.
\end{itemize}

\section{Experimental Data}
Results obtained from numerical integration are summarized in Table~\ref{tab:integral_data}.

\begin{table}[htbp]
    \centering
    \caption{Evaluation of Gaussian Integral over Intervals}
    \label{tab:integral_data}
    \begin{tabular}{cc}
        \toprule
        Interval & Integrated Area \\
        \midrule
        $[\mu - \sigma, \mu + \sigma]$ & $\approx 68.27\%$ \\
        $[\mu - 2\sigma, \mu + 2\sigma]$ & $\approx 95.45\%$ \\
        $[\mu - 3\sigma, \mu + 3\sigma]$ & $\approx 99.73\%$ \\
        \bottomrule
    \end{tabular}
\end{table}

\section{Conclusion}
LaTeX enables researchers to write reproducible, professionally structured documents effortlessly.

\end{document}
```

## 10. Common Errors & Troubleshooting

1. **Undefined control sequence:**
   - *Cause:* Typos in command names (e.g., `\begn` instead of `\begin`) or missing `\usepackage{}`.
2. **Missing `$` inserted:**
   - *Cause:* Mathematical symbols (like `_`, `^`, or Greek letters) used outside math mode.
3. **Runaway argument / File ended while scanning use of...:**
   - *Cause:* Unclosed braces `{` or unclosed environments `\begin{...}` without `\end{...}`.
4. **Reserved Characters:**
   - Always escape special symbols: `\%`, `\&`, `\_`, `\#`, `\$`, `\{`, `\}`.
