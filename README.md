## 📌 Repository Overview

This repository maintains comprehensive study guides, practical cheat sheets, command references, and code templates for five fundamental tools covered in the course curriculum:

| # | Topic | Folder | Key Topics Covered |
|---|-------|--------|--------------------|
| 1 | **LaTeX** | [`01-latex/`](01-latex/README.md) | Document structure, mathematical formulas, matrices, tables, figures, BibTeX citations. |
| 2 | **Beamer** | [`02-beamer/`](02-beamer/README.md) | Slide design, themes, frames, overlays (`\pause`), blocks, columns, verbatim code. |
| 3 | **Doxygen** | [`03-doxygen/`](03-doxygen/README.md) | Source-code documentation, `Doxyfile` configuration, Javadoc/Qt comment tags, HTML/LaTeX builds. |
| 4 | **Google Docs** | [`04-google-docs/`](04-google-docs/README.md) | Cloud collaboration, revision history, styles, citations, equation editor, Google Docs vs. LaTeX. |
| 5 | **Git** | [`05-git/`](05-git/README.md) | VCS architecture, staging, branching, conflict resolution, GitHub workflows, remote synchronization. |
